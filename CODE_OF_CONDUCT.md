# Code of Conduct

This project adopts the [Contributor Covenant v2.1][covenant].

[covenant]: https://www.contributor-covenant.org/version/2/1/code_of_conduct/

## TL;DR

Be respectful. Assume good faith. Disagree on technical matters without
making it personal. Harassment, demeaning language, and discrimination
are not tolerated.

## Reporting

Report unacceptable behaviour to **conduct@pdfmonkey.io**. Reports are
treated confidentially. The maintainers will respond within 5 business
days and may take any action they deem appropriate, including a
permanent ban from project spaces.

## Scope

This Code applies in all project spaces — issues, pull requests,
discussions, and any other forum where contributors interact in their
capacity as project participants.
